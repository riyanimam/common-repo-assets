# Examples

This directory contains example use cases and templates for GitHub repository rulesets.

## Contents

- **basic-protection.json** - Minimal protection for small projects
- **enterprise-strict.json** - High-security ruleset for enterprise projects
- **open-source.json** - Balanced rules for open-source projects
- **usage-guide.md** - Step-by-step guide for implementing rulesets

## Using These Examples

1. Choose an example that matches your project needs
2. Copy the JSON configuration
3. Modify the `name` and `conditions` to match your repository
4. Apply using GitHub CLI or API (see usage-guide.md)
